O objetivo desse sistema é uma biblioteca de item variados aonde será possível se cadastrar e ver os items que estão no site.

1.Se caso entrar pelo Ínicio clique no botão "Novo Produto".
2.Para cadastro de novos itens coloque todas as informações e clique em "Cadastrar" e ele aparecerá no catálogo mais abaixo na página.
3.Para excluir um item, clicar no botão vermelho "excluir".
4.Para Editar um dos items, clique no botão de cor amarelo e vai para cima na área do formulário e edite suas informações por ali.
5.E logo abaixo dos items ali vai estar a barra de pesquisa funcional.
